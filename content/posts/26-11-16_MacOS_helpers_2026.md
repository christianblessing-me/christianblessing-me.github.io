We all love them and use most of them in our every day lifes, little tools/helpers we use to fulfil our goals when working with our system(s). Here's my current list of tools that make my life easier. This is the successor of the [2025](https://christianblessing.me/macos-helpers-2025-edition/), [2024](https://christianblessing.me/my-little-macos-helpders-2024-edition/) and [2021 edition](https://christianblessing.me/my-little-macos-helpers-2021-edition/).

### System extensions / menubar tools

- [Espanso](https://espanso.org/) [Free]: free and mighty text replacement tool
- [Lasso](https://www.thelasso.app/) [Paid]: window manager with free definable window areas
- [BetterCmdTab](https://bettercmdtab.app/) [Free]: brings better (active) window switching to MacOS, replaced [AltTab](https://alt-tab-macos.netlify.app/) for me (what I was using for years before)
- [Shottr](https://shottr.cc/) [Paid - free option available]: my favourite screenshot and annotation tool, native macOS application and ridiculously fast; comes with a screen ruler, OCR and the possibility to create scrolling screenshots
- [Ollama](https://ollama.com/) [Free]: download, manage and run large language models on your local machine (Apple silicon)
- [Amphetamine](https://apps.apple.com/de/app/amphetamine/id937984704?mt=12) [Free]: prevents your machine from going to sleep
- [TinyCast](https://tinycast.dev/) [Free]: spotlight drop-in replacement on steroids, replaced [Raycast](https://www.raycast.com/) and [Alfred](https://www.alfredapp.com/) for me
- [Itsycal](https://www.mowglii.com/itsycal/) [Free]: tiny menu bar calendar, syncs with the macOS calendar application, supports dark mode, iso week numbers and much more
- [ICE](https://github.com/jordanbaird/Ice) [Free]: open-source menubar manager, replaced [HiddenBar](https://hiddenbar.app/) for me
- [Meeting Bar](https://meetingbar.onrender.com/) [Free]: displays upcoming Zoom, MS Teams, Skype, Google Hangouts calls in the menubar.
- [QuickRecorder](https://lihaoyun6.github.io/quickrecorder/) [Free]: open-source screen recorder
- [Obsidian](https://obsidian.md/) [Free - paid version available]: one-stop-shop for taking and organizing notes
- [Maccy](https://maccy.app/) [Free - paid version available]: MacOS clipboard manager
- [Peekie](https://peekie.app/) [Free]: simple scratchpad for daily throw-away notes

### Productivity tools

- [ClaudeCode](https://claude.ai/) [Paid]: the coding agent + harness from Anthropic
- [Codex](https://openai.com/) [Paid]: the coding agent + harness from OpenAI
- [1Password](https://1password.com/) [Paid]: password manager, simple
- [IINA](https://iina.io/) [Free]: modern media player for MacOS, replaced VNC for me
- [Zed](https://zed.dev/) [Free]: awesome IDE built in Rust, crazy fast and flexible
- [Helium](https://helium.computer/): [Free]: ungoogled Chromium the way you want to use it, adblock batteries included
- [Ghostty](https://ghostty.org/) [Free]: cross-platform terminal emulator built in Rust, replaced [wezTerm](https://wezfurlong.org/wezterm/index.html)

### WebApps

- [NextCloud](https://nextcloud.com) [Free]: own-cloud fork, self-hosted solution for file, storage, calendar, contact management - easily extendable via apps
- [ProtonMail](https://proton.me) [Paid]: privacy-first e-mail solution from Switzerland
- [MIRO](https://miro.com) [Paid]: collaborative whiteboard solution
- [Figma](https://figma.com) [Paid]: UI/UX design in the browser
